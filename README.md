# Beginning Azure Static Web Apps - Example Code

## Using This Repository

Example code for each chapter of the book [Beginning Azure Static Web Apps 2ndc Edition](https://www.amazon.nl/-/en/Stacy-Cashmore/dp/B0DTSZG89F)

The code is the end state of the chapter in the folder name.

So [Chapter-3](./chapter-3/) is the code after all steps in that chapter have been completed. That also means that it is the starting state for the Chapter 4.

## Generating Data

Also included in this repository is the application needed to seed the Cosmos DB used by the book. This can be found in the folder [dfatabase-seeder][./database-seeder]
